# Веб-приложение для генерации адаптивных тестов по теме «Изучение JavaScript»

Проект представляет собой веб-приложение для проведения адаптивного тестирования по языку программирования JavaScript. Система позволяет оценивать уровень подготовки пользователя и автоматически изменять сложность вопросов в зависимости от результатов прохождения теста.

## Принцип работы адаптивного тестирования

В основе механизма выбора вопросов лежит алгоритм изменения уровня сложности на основании ответов пользователя. Уровень сложности может принимать значения от 1 до 25.

* Начальный уровень сложности — 12.
* При правильном ответе уровень увеличивается на 3.
* При неправильном ответе уровень уменьшается на 4.
* При выборе варианта «Не знаю» уровень уменьшается на 1.

## Основные возможности

* прохождение адаптивного тестирования;
* автоматический подбор сложности вопросов;
* использование локальной базы тестовых заданий;
* получение практических задач через внешнее API;
* просмотр результатов тестирования;
* визуализация изменения уровня знаний пользователя.

## Источники тестовых заданий

Приложение поддерживает два режима работы:

1. **Локальная база вопросов** — содержит 75 заранее подготовленных тестовых заданий, хранящихся в базе данных.
2. **Генерация задач через API** — получение практических заданий из внешнего сервиса с учетом текущего уровня сложности пользователя.

## Инструкция по локальному развертыванию

### 1. Клонирование репозитория

```bash
git clone https://github.com/iwantxeeyxubleed/js_adaptive_test.git
cd js_adaptive_test
```

### 2. Создание виртуального окружения и установка зависимостей

```bash
python -m venv venv

# Для Windows
venv\Scripts\activate

# Для macOS/Linux
# source venv/bin/activate

pip install -r requirements.txt
```

### 3. Выполнение миграций и загрузка тестовых данных

```bash
python manage.py migrate
python manage.py shell < seed.py
```

### 4. Запуск сервера разработки

```bash
python manage.py runserver
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:8000/
```
