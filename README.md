# Веб-приложение для генерации адаптивных тестов по теме «Изучение JavaScript»

Проект представляет собой веб-приложение для проведения адаптивного тестирования по языку программирования JavaScript. Система позволяет оценивать уровень подготовки пользователя и автоматически изменять сложность вопросов в зависимости от результатов прохождения теста.

## Принцип работы адаптивного тестирования

В основе механизма выбора вопросов лежит алгоритм изменения уровня сложности на основании ответов пользователя (модифицированная процедура Робинса - Монро). Уровень сложности принимает дискретные значения от 1 до 24.

* Начальный уровень сложности - 12.
* При правильном ответе уровень увеличивается на 3.
* При неправильном ответе уровень уменьшается на 4.
* При выборе варианта «Затрудняюсь ответить / Не знаю» уровень уменьшается на 1.

## Основные возможности

* Прохождение адаптивного тестирования;
* Автоматический подбор сложности вопросов в реальном времени;
* Использование локальной базы тестовых заданий (60 многоуровневых вопросов);
* Интеграция с внешним API (GigaChat) для динамической генерации практических задач;
* Просмотр детализированных результатов тестирования и истории сессий;
* Визуализация изменения уровня знаний пользователя (построение графиков).

## Источники тестовых заданий

Приложение поддерживает два режима работы:

### 1. Локальная база вопросов

Содержит 60 заранее подготовленных тестовых заданий разного уровня сложности, хранящихся в базе данных SQLite.

### 2. Генерация задач через API

Получение уникальных практических заданий из внешнего ИИ-сервиса GigaChat с учётом текущего уровня сложности пользователя.

## Архитектура проекта

Система реализована по шаблону MVC/MVT, используемому в Django:

* **Model** - хранение вопросов, тестовых сессий и ответов пользователей;
* **View** - логика адаптивного тестирования и взаимодействия с GigaChat API;
* **Template** - пользовательский интерфейс на HTML и Bootstrap;
* **Database** - SQLite для хранения результатов и базы вопросов.

## Алгоритм адаптации сложности

После каждого ответа пользователя пересчитывается уровень сложности следующего вопроса.

| Действие пользователя | Изменение сложности |
| --------------------- | ------------------- |
| Правильный ответ      | +3                  |
| Неправильный ответ    | -4                  |
| Не знаю               | -1                  |

Таким образом система быстро выходит на уровень, соответствующий реальным знаниям пользователя.

## Генерация вопросов через GigaChat

При включении режима ИИ приложение:

1. Получает OAuth-токен GigaChat;
2. Формирует запрос с текущим уровнем сложности;
3. Получает вопрос в формате JSON;
4. Автоматически преобразует его в объект Question;
5. Использует вопрос в текущей тестовой сессии.

При недоступности API активируется резервный локальный набор вопросов.

## Локальное развертывание

### 1. Клонирование репозитория

```bash
git clone https://github.com/iwantxseeyxubleed/js_adaptive_test.git
cd js_adaptive_test
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

Linux / macOS:

```bash
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Выполнение миграций

```bash
python manage.py migrate
```

### 5. Загрузка эталонных вопросов

```bash
python seed.py
```

### 6. Запуск сервера разработки

```bash
python manage.py runserver
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:8000/
```
