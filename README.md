# Разработка веб-приложения для автоматизированного генерации адаптивных тестов по теме «Изучение JavaScript»

Данный проект представляет собой программный комплекс для проведения адаптивного диагностического тестирования знаний по языку программирования JavaScript (стандарт ECMA-262). Система динамически подстраивает сложность заданий под уровень подготовки конкретного респондента в режиме реального времени.

## 🧠 Архитектура и алгоритмическая основа

В основе адаптивного механизма распределения вариантов лежит **модифицированный алгоритм Роббинса-Монро (метод лестницы / Staircase Method)**. Уровень измеряемой способности респондента варьируется в диапазоне $\theta \in [1, 25]$.

* **Начальная точка:** Тестирование всегда стартует с медианного уровня сложности (уровень 12).
* **Положительная обратная связь:** При фиксации верного ответа сложность следующего задания инкрементируется на $+3$ уровня.
* **Отрицательная обратная связь:** При фиксации ошибки сложность декрементируется на $-4$ уровня.
* **Адаптивный пропуск:** При выборе варианта «Не знаю» сложность плавно снижается на $-1$ уровень.

### 🔄 Гибридная подсистема формирования контента

Программный комплекс поддерживает два независимых метода извлечения контрольно-измерительных материалов (КИМ):
1. **Локальный фонд оценочных средств (ФОС):** Структурированная реляционная база данных, содержащая 75 верифицированных тестовых заданий, равномерно распределенных по 25 уровням сложности и когнитивным кластерам.
2. **Динамический параметрический синтез (API GigaChat):** Интеграция с отечественной языковой моделью через защищенный шлюз Сбера. Вопросы генерируются ИИ «на лету» строго под текущий расчётный уровень сложности алгоритма с автоматической валидацией и парсингом входящих JSON-пакетов на стороне бэкенда.

## 🛠️ Технологический стек

* **Backend:** Python 3.14 / Django 6.0.5 (MVC architecture)
* **Frontend:** HTML5, CSS3, Bootstrap 5 (адаптивная верстка)
* **Инференс и интеграции:** GigaChat API (модель GigaChat), Requests, Управление OAuth-токенами
* **Аналитика:** Chart.js (динамический рендеринг кривой обучения в личном кабинете)
* **База данных:** SQLite / PostgreSQL
